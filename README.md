# XPBD Fracture Sim

Диплом + портфолио: симулятор мягких тел с разрывом (XPBD → FEM → разрез сетки → C++/WASM SIMD).

## Запуск в GitHub Codespaces

```bash
npm install
npm run dev
```

Codespaces сам предложит открыть порт 5173 — жми «Open in Browser».

## Roadmap

- [x] **M1** — 2D XPBD на JS: сетка треугольников, ограничения расстояния, перетаскивание, раскраска по деформации, наивный разрыв рёбер
- [x] **M2** — Ограничения площади треугольников (первый шаг к FEM): не дают треугольнику вывернуться, счётчик «вывернуто» в HUD для сравнения с выключенным ограничением
- [x] **M3** — Коротационный FEM в XPBD: градиент деформации F, полярное разложение, E и ν, главное напряжение на элементе, эрозия по прочности (см. `docs/M3-fem.md`)
- [x] **M4** — Настоящий разрез сетки: расщепление вершин по узловому напряжению, рост трещины, подсчёт отдельных кусков, «нож» (см. `docs/M4-cutting.md`)
- [x] **M5** — Spatial hash и столкновения между кусками: вершина внутри элемента чужого куска выталкивается XPBD-контактом, трение Кулона (см. `docs/M5-collisions.md`)
- [x] **M6** — Ядро на C++ → WebAssembly (clang + lld, без Emscripten), SIMD (f32x4) с раскраской элементов, бенчмарки JS vs WASM (см. `docs/M6-wasm.md`)
- [ ] **M7** — 3D (тетраэдры), мобильная оптимизация

## Структура

- `src/sim.js` — ядро на JS (эталон)
- `wasm/core.cpp`, `wasm/build.sh` — то же ядро на C++ → WebAssembly (`src/wasm/*.wasm` лежат в репозитории готовыми)
- `src/wasm-sim.js` — `WasmSim extends Sim`: тот же интерфейс, шаг выполняется в WASM
- `bench/bench.mjs` — бенчмарк: `node bench/bench.mjs`
- `src/main.js` — рендер на Canvas и ввод
