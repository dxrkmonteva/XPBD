# XPBD Fracture Sim

Диплом + портфолио: симулятор мягких тел с разрывом (XPBD → FEM → разрез сетки → C++/WASM SIMD).

## Запуск в GitHub Codespaces

```bash
npm install
npm run dev
```

Codespaces сам предложит открыть порт 5173 — жми «Open in Browser».

## Roadmap

- [x] **M1** — 2D XPBD на JS: сетка треугольников, ограничения расстояния, перетаскивание, раскраска по деформации, наивный разрыв рёбер
- [x] **M2** — Ограничения площади треугольников (первый шаг к FEM): не дают треугольнику вывернуться, счётчик «вывернуто» в HUD для сравнения с выключенным ограничением
- [x] **M3** — Коротационный FEM в XPBD: градиент деформации F, полярное разложение, E и ν, главное напряжение на элементе, эрозия по прочности (см. `docs/M3-fem.md`)
- [ ] **M4** — Настоящий разрез сетки: дублирование вершин, перестройка топологии, отдельные куски
- [ ] **M5** — Spatial hash и столкновения между кусками
- [ ] **M6** — Порт ядра на C++ → WASM (Emscripten, SIMD), бенчмарки JS vs WASM
- [ ] **M7** — 3D (тетраэдры), мобильная оптимизация

## Структура

- `src/sim.js` — ядро (потом заменяется на WASM с тем же интерфейсом)
- `src/main.js` — рендер на Canvas и ввод
