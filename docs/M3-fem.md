# M3 — Коротационный FEM в XPBD (2D)

Заготовка для главы диплома. Все формулы соответствуют коду в `src/sim.js` (`femSolve`, `updateStress`).

## 1. Кинематика элемента

Треугольник с вершинами `x0, x1, x2`; в покое — `X0, X1, X2`.

- `Dm = [X1 − X0 | X2 − X0]` — матрица покоя (столбцы — рёбра), хранится `Dm⁻¹` (`dmInv`).
- `Ds = [x1 − x0 | x2 − x0]` — текущая матрица.
- Градиент деформации: **F = Ds · Dm⁻¹** (2×2). В покое F = I.
- Объём (площадь) покоя `V0 = |det Dm| / 2` (толщина = 1).

## 2. Материал

Коротационная модель: F = R·S (полярное разложение, R — поворот, S — симметричное растяжение).

Энергия на единицу объёма:

    ψ = μ ‖F − R‖²_F + (λ/2) · tr(RᵀF − I)²

Параметры Ламе из модуля Юнга E и коэффициента Пуассона ν (плоское напряжённое состояние):

    μ = E / (2(1+ν)),    λ = E·ν / (1 − ν²)

Ближайший поворот R в 2D считается в замкнутом виде, без SVD:

    θ = atan2(c − b, a + d),   где F = [[a, b], [c, d]]

Свойство, которое проверено тестом: **инвариантность к повороту** — повёрнутая без деформации плита не получает напряжения (изменение длин рёбер 0.0000%).

## 3. Ограничения XPBD

Два ограничения на элемент (решаются последовательно на каждом подшаге):

| Ограничение | C | dC/dF | Compliance α |
|---|---|---|---|
| девиаторное (форма) | ‖F − R‖_F | (F − R) / ‖F − R‖ | 1 / (2 μ V0) |
| объёмное | tr(RᵀF) − 2 | R | 1 / (λ V0) |

Градиенты по частицам: `H = (dC/dF) · Dm⁻ᵀ`, тогда `∇x1 = H[:,0]`, `∇x2 = H[:,1]`, `∇x0 = −(∇x1 + ∇x2)`.

Поправка XPBD (λ_множитель обнуляется на каждом подшаге, схема small steps):

    Δλ = −C / (Σ wᵢ |∇ᵢC|² + α/h²),    xᵢ += wᵢ · Δλ · ∇ᵢC

## 4. Напряжение и разрушение

Из факторов растяжения s1, s2 (собственные значения S) главные напряжения Коши:

    σ_i = (2μ(s_i − 1) + λ(s1 + s2 − 2)) / s_j,    j ≠ i

Критерий (M3, «эрозия элементов»): если максимальное главное напряжение σ_max > σ_crit = порог · E, элемент удаляется. Цвет элемента — σ_max / σ_crit.

Ограничение: при удалении элемента сетка просто получает «дыру». Настоящий разрез с дублированием вершин — M4.

## 5. Что показали эксперименты

- Падение плиты при E ≥ 1e4: ни одного вывернутого треугольника, площадь сохраняется (≥ 97%).
- При E ≈ 1e3 (очень мягко) коротационная модель допускает инверсию элементов — известное ограничение, оно же аргумент в пользу Stable Neo-Hookean (возможное расширение).
- Растяжение с эрозией: разрушаются элементы у зоны с максимальным напряжением.
