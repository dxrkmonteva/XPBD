# M4 — Разрез сетки: расщепление вершин

Заготовка для главы диплома. Код: `splitVertex`, `cutStep`, `computePieces` в `src/sim.js`, нож — в `src/main.js`.

## 1. Идея

Трещина — это разрыв связности сетки. Элементы не удаляются: вершина, в которой напряжение превысило прочность, **дублируется**, и элементы вокруг неё делятся на две группы. Одна группа остаётся на старой вершине, другая переезжает на новую. Геометрия сетки не меняется, но связность — да: вдоль линии раздела соседние элементы перестают делить вершину и расходятся.

## 2. Критерий разрушения

1. На каждом элементе после шага известен тензор напряжения Коши σ (мировые оси), см. M3.
2. Узловое напряжение — среднее по площади тензоров элементов вокруг вершины.
3. Если наибольшее главное значение узлового напряжения λ₁ > σ_crit = порог · E, вершина — кандидат на разрез.
4. Направление главного напряжения `n = (cos ψ, sin ψ)`, `ψ = ½ atan2(2σxy, σxx − σyy)`. Трещина идёт **перпендикулярно n** (раскрывается вдоль растяжения).
5. За кадр расщепляются максимум `maxSplits` вершин с наибольшим λ₁ — трещина растёт плавно, а не мгновенно.

## 3. Алгоритм расщепления

Для вершины v с нормалью n:

1. Для каждого элемента, содержащего v, считаем положение центроида относительно v: знак `(c − v)·n`.
2. «Впереди» (знак ≥ 0) остаются на v, «позади» (знак < 0) получают новую вершину v′ (копия позиции, скорости и массы).
3. Если одна из групп пуста — расщепление отменяется (трещине нужны элементы по обе стороны).

У внутренней вершины раскрываются два ребра в противоположных направлениях, у граничной — одно. Дальние концы раскрытых рёбер остаются общими, поэтому у трещины появляются **кончики**, где концентрируется напряжение, и она растёт дальше. Это объясняет, почему трещина распространяется сама.

Закреплённые и перетаскиваемые вершины (w = 0) не расщепляются.

## 4. Куски

После каждого расщепления связные компоненты считаются через union-find по вершинам: элементы, делящие вершину, — один кусок. Число кусков и номер куска для каждого элемента хранятся в `pieces`, `pieceId`.

## 5. Нож

Проведи по плите: для вершин рядом с отрезком движения вызывается тот же `splitVertex`, а нормаль берётся перпендикулярно движению. Это тот же механизм, что и при трещине, но запущенный вручную.

## 6. Результаты тестов (без браузера)

- Нож по середине плиты 20×6: 7 вершин расщеплено, 2 куска, вывернутых элементов нет.
- Растяжение плиты (левый край закреплён): плита делится на 2 куска; при пороге 0.25 — на ~115-м кадре, при 0.45 — на ~196-м.
- Падение плиты без перегрузки: 0 трещин (нет ложных срабатываний).

## 7. Ограничения (задел на M5)

- Куски не сталкиваются между собой и могут проходить друг через друга.
- Трещина идёт по рёбрам сетки, поэтому её направление зависит от сетки (mesh dependence). Улучшения: сетка с нерегулярной триангуляцией или перестроение элементов вдоль трещины.
