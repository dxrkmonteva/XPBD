# M5 — Столкновения между кусками и пространственная сетка

Заготовка для главы диплома. Код: `collide`, `_inside`, `penetrationCount` в `src/sim.js`.

## 1. Зачем

После разреза (M4) куски — это независимые связные компоненты сетки. Без столкновений они пролетают друг сквозь друга. Столкновения нужны только между кусками, поэтому каждая вершина и элемент знают номер своего куска (`vPiece`, `pieceId`); внутри одного куска контакты не считаются (этим занимается FEM).

## 2. Широкая фаза: пространственная сетка

Проверять каждую вершину против каждого элемента — O(n·T). Вместо этого:

1. Плоскость делится на ячейки размера `cellSize ≈ 2.2 · шаг сетки`.
2. Каждый живой элемент записывается во все ячейки, которые пересекает его bounding box (с запасом 1 px).
3. Раскладка идёт **счётной сортировкой** (counting sort) в плоские массивы `cnt` / `items` в формате CSR — без аллокаций и без `Map`.
4. Для вершины берётся только её ячейка и перебираются элементы из неё: в среднем это десяток кандидатов вместо сотен.

## 3. Узкая фаза и контакт XPBD

Для вершины `v` куска A и элемента `t` куска B ≠ A:

1. Расстояние до рёбер: `dᵢ = s · (eᵢ × (p − aᵢ)) / |eᵢ|`, где `s` — ориентация элемента при покое. Вершина **внутри**, если все `dᵢ > 0`.
2. Берётся ближайшее ребро (`d = min dᵢ`) с внешней нормалью `n`. Ограничение: `C = −(d + skin) ≤ 0`, то есть вершина должна оказаться по другую сторону ребра.
3. Коррекция позиций (XPBD, α = 0), параметр `s` — проекция вершины на ребро `a–b`:

       λ = (d + skin) / (w_v + (1−s)² w_a + s² w_b)
       x_v += w_v λ n,   x_a −= w_a (1−s) λ n,   x_b −= w_b s λ n

   Реакция делится между вершиной и концами ребра по обратным массам — третий закон Ньютона выполняется автоматически.
4. **Трение Кулона** (позиционное): относительное касательное смещение вершины и точки ребра за подшаг гасится, но не более `μ · d`, где `μ = 0.4`.

Контакты решаются на каждом подшаге (small steps), поэтому быстро летящие куски не проскакивают: при 800 px/s сдвиг за подшаг около 1.3 px, а элемент около 15 px.

## 4. Результаты тестов (без браузера)

Левая и правая половины плиты 20×6 после ножа, правая летит навстречу без гравитации:

| Скорость | Столкновения | Вершин внутри чужого куска (в среднем за кадр) |
|---|---|---|
| 250 px/s | выкл | 47 |
| 250 px/s | вкл | 0.1 (макс. 3) |
| 800 px/s | выкл | 36 |
| 800 px/s | вкл | 0 |

Вывернутых элементов нет, симуляция устойчива. Падение двух половин на пол: 0 проникновений. Время кадра для 252 частиц: 1.6 мс с `collide` против 0.6 мс без.

## 5. Ограничения

- **Вырожденное совпадение решёток.** Если куски — копии одной сетки и скользят точно вдоль её линий, вершины лежат ровно на рёбрах чужих элементов (расстояние 0), и строгий тест «внутри» их не видит. В реальных сценах с шумом и вращением это не проявляется (проверено со сдвигом всего на 0.37 px). Надёжное решение — контакт «вершина–граничное ребро куска» с допуском.
- Проверяются только вершины против элементов. Тонкие рёбра, пересекающиеся без вершин внутри, не ловятся (редко при мелкой сетке).
- Ближайшее ребро даёт верное направление для неглубокого проникновения. При глубоком проникновении, когда вершина оказалась за серединой элемента, возможно выталкивание в «неверную» сторону.
- Внутри одного куска створки трещины друг с другом не сталкиваются.
