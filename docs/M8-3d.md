# M8 — 3D (тетраэдры)

Первый шаг в 3D: мягкий брус из тетраэдров, физика XPBD + корротационный FEM, свой WebGL2-рендер без библиотек.
Страница: `3d.html` (ссылка «3D →» в главном интерфейсе).

## Что внутри
- `src/sim3d.js` — физика. Сетка Куна (6 тетраэдров на кубик), единицы СИ (ρ = 1000 кг/м³, E в Па).
  - Девиаторное ограничение `C = ‖F − R‖`, α = 1/(2μV₀); объёмное `C = det F − 1`, α = 1/(λV₀) (устойчиво при вывернутом элементе).
  - `R` — ближайший поворот: итерации по кватерниону (Müller 2016) с тёплым стартом, 2 итерации на подшаг.
  - Массы вершин — по объёму соседних тетраэдров (тело не зависит от детализации, как и в 2D после M7.2).
  - Пол с трением, закрепление левой грани, захват вершины мягкой пружиной.
- `src/gl3d.js` — WebGL2: гладкие нормали, раскраска по ‖F − R‖, проекционная тень (stencil), орбитальная камера, выбор вершины лучом.
- `src/main3d.js` — интерфейс и ввод (мышь и тач: тянуть тело — захват, тянуть пустое место — вращение, колесо/щипок — масштаб).

## Проверка (Node, `Sim3D`)
| Тест | Результат |
|---|---|
| Падение бруса, 96 / 2592 тетраэдров, с 2 и 6 м | вывернутых 0, объём 99.8%, остаётся в покое |
| Консоль 2 м × 0.5 × 0.5, E = 5 МПа | прогиб на конце 0.20 м при 5184 тетраэдрах (формула балки 0.19 м + сдвиг) |

## Ограничения этого шага
- Нет разрезов/разрывов и столкновений между телами (в 2D они есть, в 3D — следующие шаги).
- Физика пока на JS (~7 мс на 1536 тетраэдров); WASM/GPU — позже.
- Сетка только из бруса; загрузка моделей — отдельный этап.
